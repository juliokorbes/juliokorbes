## 🚀 Featured Project

### Dashboard de Prazos e Demandas

Full stack application developed for a real operational scenario involving deadline and demand monitoring in a Real Estate Registry Office.

The system imports Excel reports, processes the information locally and transforms raw operational data into indicators, charts, filters and historical snapshots.

**Technologies**

`Java 17` `Spring Boot` `Spring Data JPA` `React` `Vite` `SQLite` `JPA/Hibernate` `Apache POI` `Recharts` `Maven` `jpackage`

**Main features**

- Excel report processing
- Multiple-file batch import
- Duplicate detection
- Historical snapshots by date and time
- Deadline and priority indicators
- Operational filters and charts
- Organized Excel export
- Local SQLite persistence
- Windows installer with embedded Java Runtime
- Local-first architecture focused on data privacy

The application was taken from requirements analysis through development, testing and Windows distribution.

> Repository kept private because the project was developed around a real institutional workflow.
